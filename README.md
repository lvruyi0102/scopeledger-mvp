# ScopeLedger MVP

Open-source, local-first MVP for tracking scope changes, change orders, notice deadlines, and generating draft notices.

## Features
- Log changes with title, description, value, deadline, status
- Visual flags for overdue / due-soon
- LocalStorage persistence (data stays in browser)
- Generate sample change-order notice draft

## Deploy
Static HTML/JS. Deploy to Vercel, Netlify, GitHub Pages, or any static host. Zero cost.
